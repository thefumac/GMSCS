# GMSCS 차세대 스마트 ISO 인증관리 플랫폼

ISO 공인 인증기관 **GMSCS (Global Management System Certification Service)**를 위한 차세대 통합 인증·심사 관리 시스템입니다.

## 🌟 핵심 기능
1. **종합 캘린더 대시보드**: 300여 고객사, 심사원별, 규격별, IAF 코드별 다차원 필터링 및 월간 일정 관리
2. **웹 심사보고서 팩 (Remark 공식 서식 100% 반영)**: 1단계/2단계 심사보고서, 시작/종결회의 안건, 이해관계 확인서, ESG-MS 부속서E 점검표
3. **심사 기간 엄격 락 (Audit Period Lock)**: 심사 시작일~종료일 기간 내에만 작성 허용 및 보안 URL 발송
4. **증빙 첨부 관리**: 조항별 필수/선택 증빙 서류 업로드 및 관리
5. **확장된 심사원단 서명 & 기업 공인 무료 이메일 인증**: 심사팀장/참석심사원/심사원보/검증심사원 자필 서명 + 기업 이메일 원클릭 확인 (비용 0원)
6. **KAB 공식 심사 MD 산정 및 수동 조정**: 공식 산정식 + 관리자 최종 합의 심사비 천단위 콤마 실시간 마스킹
7. **2중 백업 센터**: 사내 서버 PostgreSQL DB 덤프 + 외장 하드 디스크(USB 3.0) 2차 미러링 스크립트
8. **OK ESG & ISO-Record 생태계 연계**: ISO/IEC 17021 독립성 원칙 가벽 준수
